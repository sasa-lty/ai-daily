## AI Daily Radar 个人日报网页（一次性完成）

按 ai-daily-web-design.md 完成整个项目：Vite + React + TS + Tailwind + ECharts 静态站，
RSS 每日更新脚本 + GitHub Actions（cron `30 0 * * *` = 北京时间 08:30）+ GitHub Pages。

关键实现：
- `scripts/update-daily.ts`：RSS/Atom 抓取（fast-xml-parser）→ 去重 → 规则分类/评分 → 可选 LLM 增强
  （KIMI_API_KEY/OPENAI_API_KEY，OpenAI 兼容接口）→ `src/data/daily.json` + history 归档。
  失败回退：全部源失败 → 缓存；无缓存 → sample 示例数据；脚本永远 exit 0。
- `model-scores.json` 驱动雷达图（5 模型 × 7 维，source 字段，人工评分标 manual）。
- 页面 7 区块齐全：状态栏（AI 增强/规则整理/使用缓存/更新失败）/总览/三件事/热点列表
  （分类筛选+重要度排序+展开详情）/雷达图（含一句话诊断）/主题×信号等级热力图/来源说明。
- 深色情报台风格，圆角 ≤8px，图表固定高度，vite base 用 `./` 兼容 Pages 子路径。

验证结果：install/update/build/dev 全部通过；update 实跑到 12 条真实新闻（Juya+DeepMind+TechCrunch）；
浏览器截图确认桌面/移动端无溢出；控制台仅 vite debug 日志，无错误。

踩坑记录：
1. fast-xml-parser 解析 Juya RSS 报 "Entity expansion limit exceeded" → 需 `processEntities: false`，自行解码实体。
2. Juya 日报 RSS 标题只有日期 → 脚本 normalizeTitle 补来源名。
3. Vite 构建时 index.html 内联 `<style>` 触发 html-proxy bug → 移到 index.css。
4. 沙箱内 huggingface.co / LLM API 网络不可达，回退逻辑实测有效（status=rule）。
5. agent-browser 在 Git Bash 下 .cmd/node shim 均失败 → 直接跑 bin/agent-browser-win32-x64.exe；
   截图路径必须 Windows 格式；改视口用 `set viewport <w> <h>`。
